# 🚨 SSH Authentication Failure Investigation

> **Status:** Completed

## Overview

This investigation documents the analysis of multiple failed SSH authentication attempts followed by a successful login detected by Wazuh SIEM in a controlled cybersecurity home lab.

The activity was intentionally generated by repeatedly entering incorrect SSH credentials from a Kali Linux machine before successfully authenticating to an Ubuntu endpoint. Wazuh detected and correlated these events, allowing investigation of authentication failures and potential brute-force behavior.
